# option-quant-ai

Терминал для торговли опционными стратегиями на MOEX FORTS: дашборд рынка,
модуль вертикальных спредов с авто-менеджментом, аналитика конструкторского
уровня, статистика сделок и прогнозирование. Один Go-бинарь отдаёт SPA без
сборки фронтенда; рыночные данные — публичный MOEX ISS, формулы/греки/IV для
конструкторской аналитики — MOEX Options Calculator (iss/option-calc), исполнение — Alor OpenAPI.

## Возможности

**📊 Дашборд** — портфель, риск-агрегаты, греки, теплокарта, стресс-тесты,
 skew, IV Rank, арбитраж, бэктест стратегий, PWA-установка.

**🎯 Вертикальные спреды** — полный цикл:
- конструктор (Bull Put / Bear Call / Bull Call / Bear Put) с графиком
  P&L «сейчас + на экспирацию», стаканы ликвидности, панель решений
  «🎯 Система решений» (окно DTE, тренд БА, IV vs HV, качество кредита,
  ликвидность ног — взвешенная оценка 0–100);
- открытие/закрытие/ролл/дельта-хедж (бумажные или живые ордера через Alor);
- **авто-менеджер** (проход каждые 60 с): стоп-лосс, тейк-профит T/P
  (закрыть / ролл на часть прибыли / кондор), точка решения TPR по
  однодневной σ с реконструкциями (лестница, ratio, backspread-put,
  откупы хвостов, сдвиг лестницы), ролл по DTE/кредиту/страйку —
  только за нет-кредит, защита от неограниченного риска;
- **профиль позиции**: ноги (страйк/цены/IV/греки/теорцена), итоговая строка,
  кривые P&L/Дельты/Теты и поверхность волатильности — греки, теорцена и IV
  берутся напрямую из MOEX Options Calculator (цена входа — из фактического
  заполнения);
- список серий из реальных экспираций опционов (W/M/Q), точные даты.

**📈 Статистика** — весь журнал сделок: KPI (Net P&L, Win rate, Profit factor,
 ожидание, просадка, серии), кривая капитала, P&L по месяцам, распределение
 результатов, разрезы по стратегии / активу / тренду на входе / режиму
 волатильности / окну DTE.

**🔮 Прогноз** — бутстрап Монте-Карло капитала (веер перцентилей,
  вероятность плюса), прогноз по стратегиям с t-статистикой, режимные
  рекомендации («что работало в текущих условиях»). Модули статистики и
  прогноза раздельные, но питаются одним обогащённым журналом: каждая сделка
  при закрытии получает контекст входа — DTE, спот, историческую ATM IV,
  тренд-режим и IV-vs-HV.

**♻ Шорт-стрэддлы** — второй модуль: продажа ATM-стрэддла на высокой воле.
  Конструкции: классика (C+P), покрытый (+F, держит покрытие +Qty),
  синтетика (2C+F, старт с нуля). 4 правила дельта-хеджа (полоса Δ, время,
  гибрид, полоса цены), петля каждые 60 сек (стоп 2×, time-stop 14 DTE),
  встречные фьючерсы неттятся FIFO с сохранением реализованного. Профиль:
  ноги с метками цен и количествами, P&L-кривые, набегающая тета, прогноз
   первого хеджа, разбивка P&L (опционы/фьючерсы/закрытые хеджи). Всё бумажное,
   цены только живые (Alor→MOEX→отказ, заглушек нет).

**🛡 Защитная сетка** — третий модуль: покупка защитного опциона (PUT на шаг
  ниже спота + LONG-сетка фьючерса; CALL на шаг выше + SHORT-сетка в зеркале)
  после исчерпания дневного диапазона Si (сигнал из вкладки «📏 Диапазоны»:
  HALF ~45–65% ATR — разведка, READY ~65–90% — стандарт, EXHAUSTED ≥90% —
  максимальная вероятность отката). Сетка односторонняя: добор к бесстрастной
  цели-лестнице (каждые `step` пунктов от входа, не более `max_inventory`),
  тейк каждого юнита +`take_profit`, встречные ноги неттятся FIFO.
  План считает премию/тету/дельту крыла, безубыточные круги в день
  (тета ÷ (тейк − 2×комиссия); тейк ниже 2 комиссий блокирует вход)
  и 4 сценария ленты (пила/флэт/тренды). Петля
  каждые 60 сек: стоп по рублю, time-stop DTE, Telegram только о событиях.
  Всё бумажное, входы по живым тачам, оценки запрещены.

**🤖 ML** — логистическая регрессия исхода сделок + перебор сетки параметров
  с топом вариантов (в т.ч. по тенорам экспираций).

**🎲 MC-скан** — автоперебор страйки × крылья × DTE × IV для спреда,
  ранжирование по матожиданию.

**🧠 Ядро** — аналитическое ядро с ИИ-консультантом: собирает полную картину
  по инструментам вселенной (сейчас Si, RI) — тренд-контекст
 (SMA20/50/200, ADX, RSI), поверхность волатильности (ATM IV, skew, term
 structure, IV Rank, HV), ликвидность; генерирует кандидатов по фильтрам
 базы знаний и консультируется с внешней нейросетью через OpenAI-совместимый
API (настраиваемый endpoint/ключ/модель). Вердикт: конструкция, страйки,
  план входа/управления/хеджа, инвалидация. Автоскан по расписанию с
  Telegram-уведомлениями, опциональные авто-бумажные сделки при согласии
  кванта и ИИ. Вход в автo-позиции терифицируется по исполнимым ценам стакана
  (SELL нога — по бидам, BUY — по аскам), выход остаётся по теоретической цене
  (`priceOpenLegsAtMOEXTheo`). Кандидаты исключают конструкции, уже открытые
  (тот же символ + тип + пара страйков), — повторное открытие не предлагается.
  Финальное решение — за трейдером.

## Быстрый старт

```powershell
cd backend
go build ./...          # сборка
go vet ./...            # статический анализ
go test ./...           # тесты (герметичные, сеть не требуется)
go run .                # сервер на :9000
```

Переменные окружения: `PORT` (9000), `DATA_DIR` (хранилище JSON),
`ALOR_TOKEN_SECRET` (шифрование токена), `ALOR_REFRESH_TOKEN` /
`ALOR_PORTFOLIO` (или ввод через «🔑 Настройки» в UI),
`TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` (уведомления).

Docker: `docker compose up -d` (порт 9000, том `quant_data`).

Живые ордера: выпишите Refresh-токен на alor.dev/open-api-tokens и сохраните
в «🔑 Настройки» — терминал сам обновляет Access-токен (30 мин) и шлёт заявки
в Command API v2 с уникальным `X-REQID`.

## Telegram-уведомления

Сообщения идут в личный бот через российский релей
`http://193.233.87.23/bot8627553310` (прямой `api.telegram.org` из РФ
недоступен — таймаут), поэтому токен в URL не подставляется.

Настройка: в разделе «🔑 Настройки → Уведомления» (или `POST
/api/v1/settings/telegram`) сохраните `bot_token` и `chat_id`; при `test: true`
тут же придёт тестовое сообщение. Chat ID можно узнать через
`GET http://193.233.87.23/bot8627553310/getUpdates` — из поля `chat.id`
последнего update.

Бот пишет только о событиях (дайджест и generic-строка вердикта удалены):

| Случай | Когда | Текст |
|---|---|---|
| Тест при настройке | сразу после сохранения с `test: true` | «✅ Telegram-уведомления настроены…» |
| Экспирация ≤ 5 дней | каждые 15 мин, по каждой открытой позиции | «⏰ … N дн. до экспирации — закрыть или ролл» |
| Находка автоскана | топ-кандидат «Ядра» (картинка + все параметры) | «🎯 Найдено Ядром» + PNG графика P&L: экспирация/DTE, спот, страйки, кредит/дебет, макс. P&L, PoP%, счёт, причины |
| Автовход Ядра | при открытии бумажной позиции (картинка + параметры + управление) | «🟢 Автовход Ядро» + PNG графика по исполнимым ценам стакана |
| Закрытие структуры | ручное закрытие, стоп-лосс или тейк-профит | «📉 Структура закрыта: … / причина / P&L … ₽ (…%) за N дн.» |
| Предупреждение менеджера | до триггера осталось ~30% (стоп/хедж/TPR/стрик/DTE) | «⚠ Si Bull Put …: до стоп-лосса …» (кулдаун 6 ч) |
| Действие менеджера | исполнен ролл/хедж/реконструкция живого спреда | «🔧 Менеджер: HEDGE · …» |
| Хедж стрэддла | значимый хедж (полоса/мультилот; ручной — всегда) | «🔧 Стрэддл Si …: хедж BUY 1 фьюч …» (тихие доливки — только в логе) |
| Закрытие стрэддла | стоп 2×, time-stop, вручную | «📕 Стрэддл … закрыт … P&L … ₽» |

Повторы «экспирации» подавляются, пока текст не изменился; «находка» — по
ключу конструкция (символ+стратегия+экспирация+страйки, переживает рестарт
в `core_state.json`); «автовход» и «закрытие» отправляются один раз по
событию. Ключ находки фиксируется только после успешной отправки — сбой
релея повторится на следующем скане, а не потеряется. Ошибки отправки видны
в `docker logs` (`telegram: … failed: …`). Все сообщения — HTML
(`parse_mode=HTML`), спецсимволы экранируются. Отправка работает только
когда заданы и `bot_token`, и `chat_id`.

## Архитектура

```
backend/
  main.go               HTTP-хендлеры, кэши MOEX ISS, множители контрактов
  spreads.go            вертикальные спреды: план/открытие/ролл/журнал
  spreads_manager.go    авто-менеджер: машина состояний и реконструкции
  spread_advice.go      панель решений перед входом (весовая модель 0–100)
  spread_analytics.go   P&L-кривые, дельта/тета-кривые, греки ног (как в МОЕХ)
  core_ai.go, core_data.go «Ядро»: скоринг/PoP-вес кандидатов, вердикты, автоскан и автовход
   straddle.go             шорт-стрэддлы (голые/покрытые): конструктор, 4 правила дельта-хеджа, стопы
   protect_grid.go         защитная сетка (PUT+LONG / CALL+SHORT): сигнал исчерпания, план/сценарии, лестница+тейки, петля 60 сек
  ml_module.go            логистическая регрессия исхода сделок + перебор сетки (/api/v2/ml/scan)
  mc_pnl.go               Монте-Карло P&L спреда + автоперебор сетки по матожиданию (/api/v1/mc-scan)
  telegram.go, spread_chart.go Telegram-уведомления через релей, PNG-график P&L для находок
  option_mark.go          гибридные метки опционов (mid живых стаканов, иначе BS-theo по IV серии)
  spread_depth.go         стаканы ног через Alor (глубина для закрытия)
  stats_module.go       агрегаторы статистики (KPI, equity, разрезы)
  futures_range.go      дневные диапазоны фьючерсов Si/ED/RI: пункты с открытия, ATR(14), недели, интрадей 5/10/60 мин, арбитраж пары (/api/v1/range/{today,history,weeks,intraday,arb})
  forecast_module.go    Монте-Карло, t-статистика, режимные рекомендации
  expiry.go             серии/роллы по реальным экспирациям опционов
  backtest.go, iv_history.go, heatmap.go, stress.go, pnl_attribution.go, sizing.go
  calendar.go, vol_surface.go, crypto_radar.go — календарь, поверхность IV, крипто-радар
  optioncalc/           MOEX Options Calculator (iss/option-calc): серии, борд, греки/IV
  quant/                портфель, Блэк-Шоулз, греки, персистентность
  alor/                 авторизация, рыночные данные, исполнение
  secure/               зашифрованное хранилище токена
  static/               SPA: index.html (Tailwind CDN, vanilla JS, Chart.js локально)
```

Фронтенд без сборки: правите `static/index.html` — обновление по Ctrl+F5.

## Важные доменные факты

- Торговая вселенная сейчас — Si + RI (скан Ядра и селекты UI урезаны;
  кодовые пути остальных инструментов на месте, история не фильтруется).
- Живые цены или честный отказ: планы строятся из стаканов Alor, при их
  отсутствии — MOEX, протухший PrevPrice и спот-заглушки (83200 и др.)
  запрещены везде (конструкторы отказывают, аналитика метит спот как
  подозрительный, MC просит ввести вручную, менеджеры встают).
- Фьючерсные ноги метятся своим контрактом (не спотом выбранной серии).
- Встречные фьючерсные хеджи неттятся FIFO, реализованное копится в позиции
  и входит в журнал ровно один раз (`quant.SettleTrade` во всех точках
  закрытия, включая роллы-посредники).
- Доска ROPD содержит два набора инструментов под одним ASSETCODE — фильтр по
  SHORTNAME (см. `isShareOption`).
- Стоимость пункта премии: Si = 1 ₽, RI ≈ 1.66 ₽ (динамически из ISS),
  CR = 1000 ₽, SBER/SBERP = лот 100 акций, премия за акцию.
- Премиальные опционы на акции — европейские, расчётные, экспирация по средам
  по цене аукциона закрытия.
- Единицы: P&L позиций — рубли (×множитель×лоты), премии в записях — за
  единицу актива.
